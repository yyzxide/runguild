### P1：可信执行边界

**整改状态：Linux Bubblewrap 隔离已实现；可信进程兼容模式仍如实标记。**

`packages/workspace-tools/src/workspace-tools.ts:77` 在宿主机 spawn 测试进程。Worktree、shell=false、argv 白名单和精简 env 有价值，但不限制仓库脚本访问宿主文件、网络或派生进程。

`0ea8f2e` 为 `test.run` 增加 fail-closed Bubblewrap 模式：只读挂载系统运行时、可写
挂载 Task Worktree、清空环境、不挂载宿主凭据和 Docker Socket，并可隔离网络、
PID/IPC/UTS/User Namespace；`prlimit` 约束 CPU、进程、文件描述符和文件大小。
`1357af0` 将模式与限制持久化并暴露到 Web，主机缺少 `bwrap`/`prlimit` 时 Worker
拒绝启动而不静默降级。`trusted_process` 只用于个人可信环境，Evidence 与界面均
明确标记它不是 OS Sandbox。当前仍不声称经第三方审计或能安全运行任意恶意内核
攻击载荷。
